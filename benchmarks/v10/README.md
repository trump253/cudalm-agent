Generated by `scripts/benchmark_v10_release.sh` (exact-SHA discipline: the

the git SHA recorded in `environment.txt` / `summary.json`).

## Workload (canonical, unchanged since v0.6)

Four requests (A greedy; B/C/D seeded), prompt lengths 2 / 5 / 3 / 4,
generated 3 / 6 / 5 / 3, dynamic arrivals (A,B first; C after 1 step; D
after 2 steps). 27 logical sequence-token forwards
(Σ(N+m−1) = 4+10+7+6). Mode A runs each request alone (serial); mode B
admits them dynamically into the scheduler, whose decode cohorts take the
true batched GPU path (`forward_batch_with_state`). Single CUDA stream;
prefill stays serial. Qwen3.5-0.8B-Base, raw text, no chat template.

## Scope

Release benchmark ONLY — no performance pass threshold, no tuning, no
candidate evaluation, no new NCU/Nsys campaign. Numbers are for THIS
hardware / checkpoint / workload (see `docs/v10_performance.md`).
